## 5. Working environment (cloud session) — recipes that worked

- **Container:** about 7 GB RAM, 2 cores, a fixed disk allowance (it filled once; the owner approved deleting stale
  `~/.m2` jars of the old module names, an old scratch backend copy, a parked worktree's build outputs and dead
  containers). Docker present: Testcontainers supply PostgreSQL, Pub/Sub, GCS; a RabbitMQ container `rmq` on port 5679
  serves the messaging and monolith tests (`MYSMS_TEST_AMQP_URI=amqp://guest:guest@localhost:5679`).
- **Maven heap:** the owner's `backend/.mvn/jvm.config` carries `-Xmx4g` (his machine). Here cap Maven with
  `MAVEN_OPTS="-Xmx2g -XX:+UseParallelGC"`; never edit the owner's `.mvn` files. Proxy: after each container boot set the
  port in `~/.m2/settings.xml` to `${HTTPS_PROXY##*:}`.
- **Build wrapper** used by every agent (one lock shared by all worktrees; recreate it, it lives outside the repo):
  ```bash
  # wbuild.sh <worktree> <mvn args...>
  WT=$1; shift
  exec 9>/tmp/mysms-build.lock; flock 9
  pgrep dockerd >/dev/null || { setsid nohup dockerd >/dev/null 2>&1 9>&- & sleep 5; }
  docker start rmq >/dev/null 2>&1
  cd "$WT/backend" || exit 2
  MAVEN_OPTS="-Xmx2g -XX:+UseParallelGC" MYSMS_TEST_AMQP_URI=amqp://guest:guest@localhost:5679 mvn "$@"
  ```
  and the same pattern for `clients/` with `pnpm "$@"`. Run full gates as tracked background commands (never
  `nohup … &` — detached processes are reaped). A full clean gate takes 25–36 min here.
- **Targeted builds** must include `-am` (core, auth-client in the reactor): worktrees share `~/.m2`, and another
  worktree's `install` overwrites the SNAPSHOT jars.
- **Clients:** after `pnpm install`, the pinned openapi-generator jar 7.26.0 disappears — copy
  `~/.m2/repository/org/openapitools/openapi-generator-cli/7.26.0/openapi-generator-cli-7.26.0.jar` to
  `clients/node_modules/.pnpm/@openapitools+openapi-generator-cli@2.42.0/node_modules/@openapitools/openapi-generator-cli/versions/7.26.0.jar`.
  A prettier failure on ~11 untouched files means `node_modules` is missing (an unpinned prettier ran), not real drift.
- **Owner's device sync** (when his desktop app is linked): build a `git archive`/`tar` of changed files (use
  `git diff --no-renames --name-only --diff-filter=d A..B`, and `--diff-filter=D` for the deletion list — rename
  detection hides the old paths otherwise), hand it over as a file, write it into `C:\…\MySMS\.sync\`, check sha256,
  extract to a staging folder, then `rsync -rc --inplace --files-from=<chunk>` in chunks of 70–90 files (a whole-tree
  rsync times out on the bridge mount), delete the listed files (deletion needs the owner's per-session permission),
  remove `.sync`. The device repo has its own history; the owner commits.
